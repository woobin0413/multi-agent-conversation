# Security

Report a vulnerability through this repository's GitHub private vulnerability reporting when enabled. Keep credentials and personal data out of public issues and pull requests.

Actual configuration belongs in ignored local environment files or the hosting provider's secret settings. Templates contain placeholders. Source changes run a checksum-verified Gitleaks scan. These checks reduce accidental exposure; they do not certify that future changes are secure.

## Local demo scope

Keep this demo on loopback. Owner cookies, expiry, bounded inputs and streams, cancellation and process-local usage caps protect local sessions. Public multi-user hosting requires authentication, shared budgets, HTTPS and provider account spending limits. Process restarts reset the demo's counters.

Validation: 21 backend unit/HTTP tests, frontend/backend builds, synthetic-provider browser controls and cross-browser ownership checks. All three npm dependency trees reported zero audit findings at publication review.
